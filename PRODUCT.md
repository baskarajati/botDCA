# Product context

- Register: calm, precise trading operations; no claims of proven returns.
- User: a single operator running a small, explicitly approved trial.
- Purpose: monitor up to three long-only Bybit DCA baskets in one shared
  account, control re-entry per coin, preserve actual executions and assess
  readiness before activation.
- Personality: restrained and factual; distinguish local state from exchange truth.
- Anti-references: profit promises, fabricated charts, browser-stored API keys,
  unclear live toggles and dashboards that imply preview is a simulator.
- Principles: position first; evidence before readiness; exits remain available;
  stale data is visible; never arm real trading from the browser.
- Inclusion: keyboard access, text statuses, visible focus, responsive 320px layout.

The current strategy is frozen, not uniquely identified from the trader CSV.
Each coin may have a distinct initial margin, while wallet equity and reserve
remain shared. Forecasts never force-close a position. Budget, account and
activation are operator decisions, not software defaults.
